# 📊 Olist Operational Efficiency Analysis

E-commerce | Fintech | Logistics | Data Science Project

## 📌 Project Overview

This project delivers an end-to-end operational efficiency analysis within the Olist ecosystem (Brazil), combining Data Science and Business Intelligence to uncover inefficiencies across logistics, payments, and category performance.

## 🎯 Business Objectives

- Evaluate delivery performance and identify delays  
- Analyze payment methods and their operational impact  
- Detect high-risk product categories  
- Provide actionable recommendations to improve efficiency  

## 🚀 Business Impact

- Logistics: Identified a **7.83% global late delivery rate**
- Fintech: Found that **Boleto payments increase delay risk by ~1%**
- E-commerce: Detected categories with **up to 16.1% failure rate**

## 📊 Data & Methodology

- Data cleaning and preprocessing  
- Merging multiple relational datasets  
- Exploratory Data Analysis (EDA)  
- Statistical pattern detection  
- Dashboard design in Power BI  

## 🛠️ Tech Stack

- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Power BI

## 🔑 Key Insights

- Revenue is highly concentrated in credit card transactions  
- Monthly delivery times reveal seasonal patterns

This project demonstrates how analytics can optimize operations, reduce risk, and support strategic decision-making in e-commerce businesses.
